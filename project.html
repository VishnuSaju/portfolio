Lunar Lander RL

A reinforcement learning project focused on training an AI agent to autonomously land a lunar lander using Proximal Policy Optimization (PPO). Built with Python, Gymnasium, and Stable-Baselines3, the project explores reward-based learning, agent training, and performance evaluation to develop an agent capable of learning controlled and successful landings through repeated interactions with the environment.
